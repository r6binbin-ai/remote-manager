# 黑鹰 Web V5.3.1 — 实时画面显示与诊断修复

基线：Web V5.3（commit 8b1218e）+ Android V1.2.2（采集/上传成功13帧，HTTP 204）。

本次仅修复管理员网页的屏幕预览 DOM、JPEG 显示和诊断提示；给 GET 接口增加无画面原因及帧龄响应头。保留原有设备注册、心跳、授权撤销、名称/分组/备注、操作日志、演示模式/真实模式隔离，以及用户确认的页面布局。

**部署：** 将本目录 `server.js`、`package.json`、`README.md`、`public/` 上传到 GitHub 仓库根目录并 Commit。Render 自动部署后，打开后台“真实设备 → Pixel 3 → 查看”，手机上须先单独授权开始屏幕共享。

观察左侧第1个黑色画面下方诊断：
- `HTTP 200 + JPEG 尺寸`：浏览器已经收到并解码一帧，可看到实时画面。
- `HTTP 204 · no-active-session`：此 Node 实例当前没有共享会话。
- `HTTP 204 · waiting-for-first-jpeg`：共享已开始但 Node 尚未收到可用画面。
- `HTTP 204 · jpeg-expired-...`：上传已经停止或画面超过8秒。
- `HTTP 401`：管理员会话失效；重新登录。
- `画面读取异常`：检查浏览器网络/代理。

**安全边界：** 只允许 Pixel 3 手机持有人经 Android 系统明确授权后上传屏幕；后台必须登录才能读取；不保存录屏，不提供远程启动、远程控制、隐蔽截屏。

**不需要：** 再安装 Android APK、修改 Supabase 或 Render 环境变量。

备注：手机端 HTTP 204 是**上传成功**，网页端 GET HTTP 204 是**暂无画面**；这两个状态不可混淆。
