# 黑鹰安卓远程 Web V5.4 — 控制页功能键 + 顶部网络/时间信息

## 升级方式

本版本基于已部署的 Web V5.3.1 更新。保持现有 Android Agent V1.2.2（或已修复心跳与投屏的客户端）不变。

1. 备份当前 GitHub 仓库代码。
2. 在 `remote-manager` 仓库根目录上传此包里的 `public/`、`server.js`、`package.json`、`README.md`，覆盖旧文件。不要把整个上层文件夹当成一个子目录上传。
3. GitHub **Commit changes**；等待 Render 自动部署并显示 Live。现有 Render Environment 不必新增变量，不用执行 SQL，不用更新 APK。
4. 打开黑鹰后台 → 真实设备 → Pixel 3 → 查看，按 Ctrl+F5 刷新。

## 本次完成的功能

- 设备控制页延续原来 3 个画面窗口、右侧15个标签、底部 8列×6行功能键排列；不改变已有的真实设备列表。
- 顶部增加：南非约翰内斯堡时间、北京时间（分别按 `Africa/Johannesburg` 和 `Asia/Shanghai` 时区实时计时）；IP/地区（以服务器中真实上报的数据为准）；服务器连接状态、延迟及入口。
- 点顶部 **IP/服务器** 或下方同名按钮：查看设备 IP、设备地区、服务器域名/地址、版本、HTTP 健康结果、浏览器至服务器单次请求耗时及最后心跳。
- 服务器状态来自 `GET /api/health`。延迟是**网页浏览器→网站服务器**的一次请求时间，不是手机的实时网络时延。
- 48个键保留位置和名称；可用键包括：停止/开始网页观看、全屏、显示设置、网页画面亮度、网页旋转、刷新设备、网络诊断、设备信息、操作日志、运行状态、名称/备注/分组管理、IP/服务器查询、授权安全说明等。**不会远程无提示启动屏幕共享**。
- 不具备实际安全授权实现的键（如密码提取、绕过锁屏、隐蔽模式、ADB注入、禁止卸载等）保持明显禁用；不能从网页绕过 Android 授权和系统安全保护。

## 真实数据边界

- 当前 Android Agent 不向 `be_real_devices` 表上报设备公网 IP，因而真实手机 IP 可能显示 `未上报`。**不使用虚构 IP 冒充真实 IP，也不把修改设备 IP 当作已完成功能。**
- 画面亮度、方向和暂停观看是**浏览器本地预览操作**，不修改远程手机的系统设置；若要停止手机端上传，用户需在手机上点击停止共享。
- 不添加敏感权限，不采集密码、支付卡/银行信息、短信内容或隐藏录屏。

- 离线 Chromium 页面交互测试：48键生成，顶部时区标签可见，IP/服务器弹窗可打开，投屏设置、画面旋转和服务器响应可操作，无页面 JavaScript 异常。
- 该测试使用模拟设备/网络回应；**线上 V5.4 和真实 Pixel 3 功能尚待部署后验证**。
